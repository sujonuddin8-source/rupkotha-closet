# Rupkotha Fashion Storefront

Create the first working version of an e-commerce website for the kids clothing brand “রূপকথা ফ্যাশন”. Build a responsive Bengali-first customer storefront plus an admin panel route. Customer flow: Home, categories (ছেলে, মেয়ে, বেবি, নিউ বর্ন), search, product grid, product details with image/price/discount/size/color/quantity, Add to Cart/Buy Now, Cart, Checkout with name/phone/address/delivery area and Cash on Delivery, and Order Confirmation with order ID. Use local/mock data and client-side state for now, no auth, real backend or payment integration. Admin: dashboard metrics, recent orders, product management, stock/size management, order list and status controls (pending/confirmed/shipped/delivered). Visual style: simple modern kids fashion, white/light background, soft pink and purple accents, rounded corners, generous whitespace, Bengali typography, polished real-looking kids clothing imagery, crown-style brand identity. Make navigation, search/filter, cart, checkout and confirmation functional. Keep it responsive and structured so an Android client can later reuse the same product/order model and design language.
